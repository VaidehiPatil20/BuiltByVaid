# Media provenance and usage

- `assets/scrunchie/`: existing original Scrunchie Robot videos and stills, previously extracted from the user-provided CMU presentation.
- `assets/hat/interface-crop.webp`: cropped figure from slide 5 of `HRI_ProjectPresentation.pdf` inside `00HAT-main.zip`.
- `assets/hat/classifier-crop.webp`: cropped confusion matrix from slide 9 of the same presentation. The crop excludes participant portraits.
- `assets/haptics/actuator-test.webp`: original photograph from `Vibrotactile Motor Skill Learning Update (Aug 18).pptx`, image22.png.
- `assets/haptics/mounting-comparison.webp`: original photograph from that PPTX, image25.png.

The site intentionally does not include the IRB consent form, participant videos, unreviewed research recordings, or any generic/stock images for these projects. Verify permission to publicly post project media.

The YouTube Short for Bob the Farmer is linked externally; it has not been downloaded or converted into a GIF. Upload the original video if you want a locally hosted loop.
