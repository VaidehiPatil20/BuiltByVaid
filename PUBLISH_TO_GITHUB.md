# Publish Built by Vaid

This folder is the complete, GitHub-ready website.

1. Open https://github.com/VaidehiPatil20/BuiltByVaid
2. Switch to your preferred branch (or create a new branch).
3. Upload `index.html` and the complete `assets/` folder at the repository root, preserving directory structure.
4. Commit the changes.
5. Review the site before merging into `main` to publish through GitHub Pages.

Do not upload personal addresses, GPA, private research-participant videos, or the original consent forms.

All project images in this package are from the user's supplied files, not generated imagery.
