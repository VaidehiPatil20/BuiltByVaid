# Vaidehi Patil — Robotics Portfolio

Static website ready for GitHub Pages.

## Publish
1. Create a **public** GitHub repository named `YOUR_USERNAME.github.io`.
2. Upload the **contents** of this folder to the repository root (index.html and assets/).
3. In Settings → Pages, select **Deploy from a branch**, branch `main`, folder `/ (root)`.
4. Visit `https://YOUR_USERNAME.github.io` after deployment.

## Update content
- Edit `index.html` in any code editor. Project cards appear in the `#projects` section.
- Put approved project photos/videos in `assets/` and reference them with relative paths.
- Add a resume PDF named `resume.pdf` and a link `<a href="resume.pdf">Resume</a>` to the hero actions.
- Replace the MOLG and Motional abstract art with authorized photos or videos.
- For company work, avoid confidential internal screenshots, proprietary code, unannounced features, and unpublished performance figures.
